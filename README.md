# De Bril — homepage

Static homepage for De Bril (BOSYM Pvt Ltd), built from the client-approved Figma design.

- `index.html`, `site.css`, `site.js` — no build step; open `index.html` or serve the folder.
- Links for Shop, About, Find a store, Contact and product search point to the live site, buydb.in.
- Campaign photos are placeholders; the Frames billboard image was generated in Google Flow from the real 1003 frame.

After editing site.css or any .js file, run `python3 bust.py` so browsers fetch the new version instead of a cached one.
